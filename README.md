# Claude Personal Plugins

Personal Claude plugin marketplace for Cowork and Claude Code.

## Included plugin

### Sonnet Workers

Provides `sonnet-workers:sonnet-implementer`, a Sonnet subagent for delegated repository exploration, routine implementation, debugging, refactoring, test creation, and code review.

Architectural decisions, governance interpretation, scope control, and final approval remain with the parent agent.

## Add to Cowork

Open the plugin Directory, select **+**, choose **Add from a repository**, and enter:

`execasstlgugingoog-jpg/claude-personal-plugins`

Then install or enable **Sonnet Workers** and start a new Cowork session.
